# AMBMUSIC 구현 계획

## 방향

어디에도 도착하지 않아도 되는 작은 강. 문자로 그린 산과 숲 사이를 배가 천천히 흐르고, 네발 노란 친구가 자기 속도로 시간을 보낸다. 레퍼런스의 기법과 분위기를 참고하되 캐릭터, 장면, 소리와 UI는 직접 만든다.

영상 링크는 현재 환경의 네트워크에서 403으로 차단되어 직접 관찰하지 못했다. 첨부 화면도 전달되지 않아 사용자의 설명을 시각적 요구사항의 기준으로 삼았다. 현재 프로토타입은 영상의 재현 정확도를 검증한 결과물이 아니다.

## 첫 화면과 정보 구조

- 따뜻한 회백색 프레임, 여백이 넓은 정렬, 작은 모노스페이스 라벨.
- 산·숲·물·배·캐릭터로 구성한 실시간 ASCII 장면.
- 오른쪽 위 검은 플레이어: 곡명, 아티스트, 재생 상태와 Spotify 연결. 긴 곡명은 말줄임. 자연 소리 모드와 실제 Spotify 데이터를 구분한다.
- 아래 컨트롤: 캐릭터 동작 5종, 자연 소리 재생 및 믹서, 타이머, 몰입 모드, 장면 설정.
- 모바일에서는 재생 카드를 장면 하단에 배치하고 캐릭터 동작 줄과 오디오 조절 줄을 나눈다.

## 배경과 화면 구성

기본 화면은 참조 사진처럼 검은 중앙 숲, 밝은 상단 ASCII 구름, 하단의 가로 물결과 중앙 낚시 캐릭터다. 데스크톱 16:9, 모바일 420px 장면을 사용하며 곡 정보는 오른쪽 위 얇은 한 줄 바에 둔다.

- 배경 문자는 10px, 모바일 11px 모노스페이스다. 기기 픽셀 비율로 직접 그리며, 축소 효과 버퍼를 다시 확대하지 않는다. 저화질에서도 글자 크기와 DPR을 유지한다.
- 문자 행을 타일로 캐시하고 실시간에는 타일 이동과 마스크 합성만 수행한다. 캐릭터는 포즈·위치가 바뀔 때만 갱신한다. 합성 상한은 60fps다.
- 숲은 문자에 적용하는 보이지 않는 가림 마스크로 표현한다. 배경의 보이는 표시는 ASCII뿐이며, 캐릭터·배·소도구는 별도 2D 픽셀 아트다.
- 6풍경, 시드 재생성, 직접 선택과 180초 자동 여행·20초 연결을 유지한다. 새 타일만 생성하고 지난 범위는 해제한다.
- 기본 다크 모드·침엽수 강·시드 1729이며 화이트 모드도 제공한다. 풍경 저장 키는 `ambmusic.scene.v2`를 사용하며 기존 버전 키는 그대로 보존한다. 모드 선택은 `ambmusic.theme.v2`로 저장해 이전 화면의 기본 흰색에서 새 참조 구도로 전환한다.

자세한 출처와 구현은 [렌더링 조사](RENDERING_RESEARCH.md), 측정은 [검증 기록](VALIDATION.md), 배포는 [Vercel 안내](DEPLOYMENT.md)를 따른다.

## 캐릭터

16×12 픽셀의 노란 `#D9B34E` 몸통, 검은 두 점눈, 두 팔과 짧은 네 다리로 구성한다. 참조 사진에 맞춰 몸통·팔·금빛 배의 비율을 조정하고 왼쪽에 낚싯대를 세운다. 기본 동작은 낚시이며 쉬기·노 젓기·낮잠·망원경도 유지한다. 캐릭터와 장면은 음악의 박자·음량과 독립적이다.

## Spotify

이 저장소는 공개 프런트엔드 앱이다. Client Secret을 넣지 않는다.

- Authorization Code + PKCE(S256), 무작위 state, 10분 유효 로그인 요청, 일회용 code verifier.
- 공식 Web Playback SDK, 기기 활성화, 현재 곡·아티스트·상태 표시, 이전/다음 곡, 재생/일시정지, 음량.
- 토큰은 메모리에서만 보관한다. 새로고침 시 다시 연결해야 한다. 리프레시 토큰으로 현재 세션의 액세스 토큰을 갱신한다. PKCE 임시 정보만 sessionStorage에 저장하며 콜백 처리 시 제거한다.
- 별도 음악 카탈로그나 추천 엔진은 범위에 넣지 않는다. 사용자는 Spotify 앱에서 음악과 AMBMUSIC 기기를 선택한다.
- 브라우저 재생에 Spotify Premium이 필요하며, 개발 모드의 앱 사용자 허용 목록·할당량·배포 승인 요건은 출시 전에 현재 공식 대시보드에서 확인한다.
- 리디렉션 URI는 Spotify 앱 설정과 완전히 일치해야 한다. 개발 시 `http://127.0.0.1:5173/`, 배포 시 HTTPS를 사용한다. 실제 등록 가능 여부와 보안 요건은 최신 문서로 재확인한다.
- 기본 Client ID가 없으면 연결 준비 중으로 표시한다. 자연 소리는 독립적으로 동작하며, 실제 Spotify 로그인·음악 재생은 계정 및 앱 설정 후 검증해야 한다.
- 프로토타입은 SDK 오류와 Premium 제한을 안내한다. 스트리밍 음원을 다운로드·변형·저장하지 않는다.

Spotify 콘텐츠와 시각 미디어의 결합, 브랜딩·메타데이터·상업화·재생 UI 요구사항은 공개 출시 전 최신 Developer Policy 검토가 필요하다. 장면은 음악과 동기화하지 않지만 이것만으로 정책 준수를 단정할 수 없다. 정책상 결합이 허용되지 않는 경우 Spotify는 외부 재생 링크로 한정하고 사이트는 독립 자연 소리 모드로 제공한다. 현재 환경에서는 공식 문서 접근이 차단되어 최신 정책을 직접 검증하지 못했다.

## 차별점

### 이번 프로토타입

1. **나만의 고요**: 물·바람·새소리를 각자 조절. Web Audio로 생성하므로 음원 다운로드와 별도 음원 라이선스가 필요 없다.
2. **친구의 자유 시간**: 생산성을 요구하는 게임 대신, 동작 선택과 느린 자동 전환.
3. **느슨한 집중 타이머**: 15·25·45분. 종료 시 조용한 문구만 표시하며 음악을 강제로 끊지 않는다.
4. **몰입 모드**: UI를 숨기고 장면만 남기기. F와 Esc 단축키.
5. **기기와 감각 배려**: 움직임 줄이기, 화질 선택, 소리 자동 재생 금지.

### 이후 후보

- 아침 안개·비 오는 저녁·달빛을 수동 선택. 사용자 위치는 요청하지 않는다.
- 몰입을 방해하지 않는 희귀한 작은 사건: 반딧불이, 떠다니는 잎, 멀리 스치는 새.
- 개인 저장 장면: 날씨·문자 밀도·자연 소리 조합만 저장. Spotify 토큰이나 개인정보를 공유 URL에 넣지 않는다.
- 타이머 알림 소리와 자동 종료는 선택형 설정으로 확장.
- 장시간 메모리·전력 측정과 더 풍부한 2D 스프라이트 동작.

## 검증과 다음 단계

타입 검사와 배포 빌드, 데스크톱/모바일 Chromium의 실제 Canvas 2D 화면, 테마 전환·선택 저장, 파노라마 비율과 수평 흐름, 동작 선택, 사용자 클릭 이후 오디오 상태, 믹서, 타이머, 몰입 모드, 모션 감소, Canvas 폴백, 인증 콜백 거부 경로를 검증한다. Spotify는 Client ID와 Premium 사용자로 실제 로그인·DRM 재생·기기 전환을 검증하기 전까지 통과했다고 표시하지 않는다.

프로토타입 피드백 이후: 장면 아트 개선 → 실제 Spotify 통합 검증 및 정책 검토 → Safari/iOS/Android 성능·오디오 검증 → HTTPS 배포와 보안 헤더 설정 순으로 진행한다. 이후 품질 작업에서는 음소거 상태 변경, 인증 실패 복구, 타이머 백그라운드 복귀, 장시간 메모리 사용도 확인한다.
