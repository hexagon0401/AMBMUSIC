# 구현 검증 기록

## 빌드와 배포 결과물

- Node.js 24에서 `npm ci --cache /tmp/ambmusic-npm-cache --no-fund --no-audit` 후 `npm run build` 성공.
- TypeScript 검사와 Vite 프로덕션 빌드 성공. JavaScript gzip 약 18.7KB, CSS gzip 약 5.9KB.
- `npm audit --audit-level=low`: 알려진 취약점 0개.
- Vercel 프리셋·Node engines·잠금 파일 일치 확인. `dist/third-party-notices.txt`에 설치된 simplex-noise의 MIT 고지 전문이 포함됨을 확인.
- 실제 Vercel 배포는 수행하지 않음. `vercel.json` 헤더는 설정을 검증했으며 실제 Vercel 응답 헤더를 측정한 것은 아님.

## 지형·브라우저 검사

총 16개 검사의 각 시나리오를 확인했다. 전체 실행에서는 15개가 통과했고 가상 시계를 사용하는 기존 타이머 검사 한 건이 30초 제한 시간을 초과했다. 스냅샷에는 정상 종료된 타이머가 확인되었다. 해당 검사만 모션 감소 모드로 실행하도록 분리한 뒤 동일한 시간·종료 문구 assertions를 유지하여 재실행했고 통과했다. 타이머와 별개로 배경의 실제 이동과 정지·재개는 별도 검사에서 검증했다.

- 기본 데스크톱 조작, 실제 AudioContext 시작·정지, 믹서, 동작 선택, 타이머와 몰입 모드.
- 모바일 가로 넘침과 대화상자, Canvas 미지원 폴백, 모션 감소, 위조 OAuth 콜백 거부.
- 테마 전환·저장, 파노라마 비율과 좌→우 흐름.
- 6풍경 × 2테마 × 2화면의 24개 화면 조합. 고정 시드 1729로 캡처.
- 풍경 선택·새 시드·테마 변경에서 오디오와 타이머 상태 유지, 새로고침 후 풍경 설정 복원.
- 활성 시간으로 계산하는 여행·20초 보간·중간 정지·재개, 숨긴 탭 시간 제외와 복귀 시 점프 방지.
- 모든 풍경의 시드 재현, 양옆 조각의 동일한 경계 좌표, 지면에 고정된 식생 뿌리.
- 30분 진행에 해당하는 모델 이동과 100회 재생성의 캐시 상한. 실제로 브라우저를 30분 연속 실행한 검사는 아님.

## 배포 빌드 기능 검사

`npm run preview -- --port 4173 --strictPort`로 dist를 제공한 뒤 다음 검사를 실행했다.

```sh
AMBMUSIC_BASE_URL=http://127.0.0.1:4173 npm run test:e2e -- --grep 'mobile has|selecting, regenerating|untrusted OAuth'
```

3개 모두 통과했다. 모바일 조작, 풍경·시드 변경, 오디오·타이머 유지, 테마·설정 복원, OAuth 거부 경로를 배포 번들에서 확인했다. 루트 HTML의 해시된 assets와 MIT 고지 파일도 HTTP로 확인했다.

## 성능 측정과 한계

클라우드 headless Chromium, 1440×560 대표 장면에서 최종 ASCII 문자 전용 변경 후 대표 장면의 렌더 명령 비용은 평균 약 17.33ms, p95 약 52.8ms였다. 자동 화질이 저화질 효과로 전환되었으며 활성 지형 조각 24개, 문자 캐시는 개수 상한 이내를 기록했다. 100회 재생성 후에도 조각 수와 문자 캐시 상한을 유지했다. 이 수치는 초기 캐시 생성과 클라우드 CPU의 영향을 포함하며 안정적인 30fps 달성을 증명하지 않는다. 설정의 최대 30fps는 상한이다.

렌더 비용은 그리기 명령을 실행하는 JS 구간을 측정하며 디스플레이 표시 지연·GPU 비용·배터리 사용량은 별도다. 실제 모바일·Safari/iOS의 프레임·전력 측정, 실계정 Spotify 로그인·DRM 재생·토큰 갱신은 남아 있다. 필요한 계정과 고정 HTTPS 콜백 설정 없이 성공했다고 간주하지 않는다.

화면과 측정 JSON은 검사 실행 시 `/tmp/ambmusic-artifacts`에 생성된다. 외부 서비스로 업로드하거나 실제 배포하지 않았다.


## 최종 ASCII 전용 변경

이전 배경에는 문자와 색면·그라데이션·지층 선·반사 이미지가 혼합되어 있었다. 최종 버전은 한 가지 바탕색 위에 산·나무·눈·구름·물결·반사·해와 달을 모두 7비트 ASCII 문자로 그린다. Path2D는 문자의 모양 제한과 가림을 위한 보이지 않는 마스크로만 사용한다. 캐릭터·배와 조작 UI는 별도의 픽셀·DOM 표현이다.

배경 캔버스와 문자 캐시의 실제 그리기 호출을 추적해 일반 색 채움, 선, 비 ASCII 문자, 문자 캐시 이외의 이미지가 있으면 실패하는 검사를 추가했다. CSS 그라데이션 덧씌우기와 정지 폴백이 뒤에서 드러나지 않는지도 확인한다. 이 조건으로 24개 화면 조합이 통과했다. 캐릭터 다리는 길이 1논리 픽셀로 줄이고 배에 닿도록 위치를 조정했다.

전체 16개 검사 실행이 통과했다. 이후 성능 측정에서 발견한 수면 글자 크기의 연속값에 따른 캐시 재생성을 고정 크기 단계로 수정했고, 영향을 받는 24개 화면 조합과 성능·캐시 검사 3개를 다시 실행해 모두 통과했다. 최종 빌드도 성공했다.

Production CLI 배포는 `No existing credentials found`, 공식 로그인은 네트워크 오류, 임시 배포도 로그인 요구와 네트워크 오류로 실패했다. 사용자 요청에 따라 GitHub 저장소를 통한 Vercel Import 경로로 전환한다. 실제 Vercel 사이트 URL은 아직 확인하지 않았다.
