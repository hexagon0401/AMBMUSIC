# 참조 구도·문자 선명도·프레임 검증

## 변경과 확인 범위

이전 버전은 구름·수면을 45~65% 크기로 그린 뒤 확대하고, 512 높이 좌표계에 맞춰 작은 문자와 전체 화면을 함께 확대했다. 현재는 화면 크기에 맞춘 10 CSS px(모바일 11 CSS px) 문자 행을 기기 DPR로 직접 캐시한다. 효과 축소 배율은 1이며 소수점 DPR도 그대로 사용한다. 저화질·고화질 설정에서도 글자 크기와 DPR은 유지된다.

화면은 첨부한 참조 이미지의 구도를 따른다: 어두운 `#222222` 바탕, 큰 검은 중앙 숲, 밝은 상단 문자 구름, 하단 가로 물결, 중앙 낚시 친구와 금빛 배, 오른쪽 위 얇은 곡 정보 바. 캐릭터는 기존 요청의 노란색을 유지한다. 원본 이미지의 픽셀 단위 복제나 원본 영상의 움직임을 그대로 재현했다는 의미는 아니다.

## 빌드와 브라우저 검사

- `npm run build`: TypeScript와 Vite 프로덕션 빌드.
- `npm run test:e2e`: 18개 통과. 기본 조작·실제 AudioContext·믹서·타이머·몰입 모드·Canvas 폴백·모션 감소·OAuth 거부·테마·파노라마·풍경 설정 유지·여행 시간·지형 재현성과 캐시·프레임 검사.
- 6풍경 × 2테마 × 2화면의 24개 조합을 고정 시드 1729로 캡처한다.
- 배경의 실제 그리기 호출을 추적해 색면·선·비 ASCII 문자·문자 레이어 외 이미지 사용을 거부한다. 배경 CSS 그라데이션과 정지 폴백의 덧씌움도 검사한다.
- 이전의 `drawImage` 호출 횟수 기준 대신 실제로 그려진 비공백 문자 수를 세어, 행 캐시 합성에서도 문자가 충분히 그려졌는지 검사한다.
- DPR 1.25와 2에서 메인 캔버스와 문자 타일이 물리 픽셀 1:1인지, 저·고화질에서 문자 크기를 유지하는지 검사한다.
- 정상 이동 300ms 동안 문자 타일 생성 횟수가 늘지 않는지 검사한다. 100회 재생성 후에도 보이는 조각과 캐시 개수 상한을 확인한다.
- 활성 시간·모션 감소·숨긴 탭 정지 및 복귀, 30분 진행에 해당하는 모델 이동도 검사한다. 실제 브라우저를 30분 연속 실행한 검사는 아니다.

## 측정된 성능

Chromium 기본 렌더링 백엔드를 사용했다. 과거 WebGL 검사에 필요했던 강제 SwiftShader 옵션은 현재 Canvas 2D 테스트에서 제거했다.

| 조건 | 관측 결과 |
| --- | --- |
| 1440×780, DPR 2, 검은 숲, 일반 브라우저 설정 | 약 59 FPS, 그리기 명령 평균 약 6.2ms / p95 약 7.4ms |
| 자동화 fixture 1440×560, DPR 1.25 | 약 60 FPS, 명령 평균 약 0.23ms / p95 약 0.30ms |
| 자동화 fixture 1440×560, DPR 2 | 약 60 FPS, 명령 평균 약 0.27ms / p95 약 0.40ms |
| 1440×560, DPR 2 타일 캐시 | 25개, 약 31.7MB; 지형 마스크 7개 |

캐시 생성이 끝난 최근 프레임 기준이며 초기 생성 비용은 별도다. DPR 검사에서는 프레임 속도 45 FPS 초과와 p95 그리기 명령 비용 32ms 미만도 확인한다. JS 명령 비용은 GPU 완료·디스플레이 지연·전력 사용량을 대신하지 않으며, 모든 기기에서 60 FPS를 보장하지 않는다. 실제 Safari/iOS/Android의 장시간 프레임·배터리 측정은 남아 있다.

## 배포와 한계

Vercel 설정과 MIT 고지 파일을 포함한다. 로컬 프로덕션 번들에서도 모바일 조작·풍경/시드 변경·오디오/타이머 유지·OAuth 거부 경로를 다루는 3개 검사가 통과했다. 변경은 GitHub `main`에 푸시해 연결된 Vercel 프로젝트에서 다시 빌드하는 흐름을 사용한다. 실제 배포 완료 여부는 Vercel의 Deployment 상태와 발급 URL로 확인해야 한다. Spotify 실계정 로그인·DRM 재생·토큰 갱신은 기존과 같이 미검증이다.

스크린샷과 측정 JSON은 검사 실행 시 `/tmp/ambmusic-artifacts`에 생성한다. 특히 `native-dpr-1.25.json`, `native-dpr-2.json`에 DPR·글자 크기·효과 배율·캐시·프레임 속도를 기록한다.


## Spotify 연결 보완

`tests/spotify.spec.ts`의 5개 브라우저 검사에서 PKCE callback과 기기 전환, 곡/앨범/플레이리스트 재생 요청, 모바일 활성화 호출, 이전/다음/음량, 토큰 갱신 중복 방지와 refresh token 보존, 만료 실패와 기기 접근 제한 복구, 오래된 SDK 이벤트 무시, URL 검증과 손상된 인증 세션 거부를 확인한다. Spotify 응답과 SDK를 대체한 검사이며 실제 계정·DRM 음원 재생 성공을 뜻하지 않는다. 기존 앱 상호작용 8개도 통과했다.
