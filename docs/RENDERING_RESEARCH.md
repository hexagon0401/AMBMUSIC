# ASCII 풍경 생성: 조사와 적용

## 선택

Canvas 2D와 작은 시드 노이즈 라이브러리 `simplex-noise@4.0.3`를 사용한다. 캐릭터와 가까운 전경은 독립 투명 캔버스에 그린다. 최종 배경은 단색 바탕 위의 ASCII 문자뿐이다. 지형 Path2D는 문자 영역과 가림을 계산하는 보이지 않는 마스크이며, 색면이나 선으로 화면에 표시하지 않는다. GPU 렌더러나 서버, 외부 이미지·음원 CDN은 초기 장면에 필요하지 않다.

아래 자료는 공식 GitHub 소스와 라이선스, npm 메타데이터로 확인했다. YouTube 영상, NVIDIA GPU Gems 문서, Vercel 웹 문서는 현재 네트워크의 403 제한으로 직접 열람하지 못했다. Vercel Vite 프리셋은 [공식 framework 소스](https://github.com/vercel/vercel/blob/main/packages/frameworks/src/frameworks.ts)의 Vite 감지, `VITE_` 접두어와 `dist` 출력을 확인했다. 원본 영상과의 픽셀 단위 일치 여부를 검증했다는 의미는 아니다.

| 자료 | 라이선스 | 조사한 기능 | 결정 |
| --- | --- | --- | --- |
| [simplex-noise.js](https://github.com/jwagner/simplex-noise.js/tree/main) | MIT | 시드 PRNG를 받는 `createNoise2D`/`createNoise3D`, 개별 함수 트리 셰이킹 | 4.0.3을 정확히 고정해 설치. 지형·눈선·구름·물 교란에 적용 |
| [FastNoiseLite](https://github.com/Auburn/FastNoiseLite) | MIT | OpenSimplex, cellular, fractal, domain warp, JS/TS 지원 | 다양한 노이즈를 묶은 대안. 현재 범위는 simplex와 간단한 합성으로 충분해 제외 |
| [Three.js Water](https://github.com/mrdoob/three.js/blob/dev/examples/jsm/objects/Water.js) / [Water2](https://github.com/mrdoob/three.js/blob/dev/examples/jsm/objects/Water2.js) | MIT | 여러 크기의 움직이는 법선, 수면 반사, 흐름 방향, 반사량 | 표현 원리만 참고. 셰이더·이미지를 복사하거나 Three.js를 다시 설치하지 않음. 반사 위치를 다시 샘플링한 ASCII 수면과 파동 합성은 직접 작성 |

`simplex-noise`의 `master` 브랜치 문서에는 구형 생성자 API가 남아 있어 그대로 사용하지 않았다. 실제 4.0.3 패키지와 `main` 문서의 함수형 API를 기준으로 구현했다. 별도 alea 의존성 대신 프로젝트의 고정 PRNG를 각 노이즈 함수에 따로 전달한다.

## 현재 화면과 표현

- **구도:** 데스크톱은 16:9다. 새 버전 첫 방문의 기본 풍경은 침엽수 강·시드 1729이며, `#222222` 바탕, 중앙의 큰 검은 숲 실루엣, 상단의 밝은 문자 구름과 하단의 가로 물결이다. 곡 정보는 오른쪽 위 한 줄 바, 캐릭터와 배는 수면 중앙에 둔다. 모바일은 같은 구도를 420px 높이로 조정한다. 사진에 없는 큰 제목·좌표·자막 패널은 장면에서 숨긴다.
- **문자:** 모노스페이스 10 CSS px, 모바일 11 CSS px다. 크기는 장면 높이나 저화질 설정에 따라 작아지지 않는다. 화면 DPR(최대 3, 소수점 DPR 포함)에 맞춰 직접 그린다. 한 행의 문자들을 네이티브 `fillText`로 묶어 그리므로 작은 아틀라스나 45~65% 효과 버퍼를 확대하는 단계가 없다.
- **구름:** 두 깊이의 2D 노이즈 문자 필드가 각각 초당 1.6/4.5 CSS px로 이동한다. 높은 부분의 밝은 행과 끊어진 문자 뭉치로 구름을 표현한다. 생성 디테일은 노이즈 항 개수만 바꾸며 글자 해상도는 고정한다.
- **숲과 지형:** 시드 기반 지형 조각에서 캐시한 Path2D는 문자를 지우는 마스크로만 사용한다. 산·나무를 색면으로 칠하지 않고, 문자 사이의 검은 여백으로 실루엣을 만든다. 설산·절벽·사암·해안·갈대 풍경도 공통 수평선에서 연결한다.
- **수면:** 수면을 세 깊이의 문자 띠로 나누고 9/16/25 CSS px/s로 이동시킨다. 낮은 주파수 노이즈와 긴 가로 행으로 반짝이는 물결을 만든다. 숲 마스크를 수평선 아래에 약하게 반전해 반사를 표현한다. 비트맵을 찌그러뜨리거나 문자를 늘이지 않는다.
- **캐릭터:** 16×12 두 색 픽셀 친구의 몸통과 팔 비율을 넓히고, 다리는 1픽셀로 유지한다. 캐릭터는 노란색 `#D9B34E`, 배는 금빛 갈색이다. 낚싯대는 사진처럼 왼쪽에 세운다. 작은 픽셀 원본만 정수 배율로 확대하며 배경 문자 확대와는 별개다.
- **여행:** 6종 풍경·시드 재생성·직접 선택·180초 자동 여행·20초 연결을 유지한다. 텍스트는 새 조각이 필요할 때만 생성하고, 보이는 범위를 벗어난 조각은 정리한다.

## 캐시·프레임·측정

실시간 루프는 캐시된 문자 타일을 합성하고 숲 마스크를 적용한다. 행 문자열·노이즈·폰트 측정을 매 프레임 반복하지 않는다. 캐릭터 레이어도 실제 포즈나 위치가 달라질 때만 다시 그린다. 숨겨진 탭에서는 시간과 그리기를 멈추고, 움직임 줄이기에서는 조작 시에만 다시 그린다.

타일 이동은 물리 픽셀 경계에 맞추고 이미지 보간을 끈다. 메인 캔버스와 모든 문자 타일의 원본/표시 물리 픽셀 비율이 1:1인지 테스트한다. 화면을 확대하는 단계를 없애면서 60fps를 상한으로 합성한다. 저화질에서도 DPR과 글자 크기를 유지한다.

`getDiagnostics()`는 최근 120프레임 명령 비용, rAF 기반 프레임 속도, 레이어 생성 횟수, 문자 크기·DPR·효과 배율, 캐시 메모리를 제공한다. 1.25배/2배 DPR에서 45fps 이상, p95 명령 비용 32ms 이하, 정상 이동 중 타일 재생성 없음, 저·고화질에서 글자 해상도 유지 여부를 검사한다. 과거 WebGL 검사 때문에 강제했던 SwiftShader 옵션은 현재 Canvas 2D 검사에서 제거하고 Chromium 기본 렌더러를 사용한다. 실기기 성능과 디스플레이 지연·전력은 별도 측정이 필요하다.

## 라이선스

실제 번들에 포함하는 외부 런타임 패키지는 simplex-noise다. 설치된 4.0.3의 MIT 전문을 `public/third-party-notices.txt`에 보관하며, Vite가 이를 배포 루트 `/third-party-notices.txt`로 복사한다. 다른 프로젝트의 셰이더나 이미지·캐릭터 파일은 포함하지 않는다.
