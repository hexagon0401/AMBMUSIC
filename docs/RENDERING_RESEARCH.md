# ASCII 풍경 생성: 조사와 적용

## 선택

Canvas 2D와 작은 시드 노이즈 라이브러리 `simplex-noise@4.0.3`를 사용한다. 캐릭터와 가까운 전경은 독립 투명 캔버스에 그린다. 최종 배경은 단색 바탕 위의 ASCII 문자뿐이다. 지형 Path2D는 문자 영역과 가림을 계산하는 보이지 않는 마스크이며, 색면이나 선으로 화면에 표시하지 않는다. GPU 렌더러나 서버, 외부 이미지·음원 CDN은 초기 장면에 필요하지 않다.

아래 자료는 공식 GitHub 소스와 라이선스, npm 메타데이터로 확인했다. YouTube 영상, NVIDIA GPU Gems 문서, Vercel 웹 문서는 현재 네트워크의 403 제한으로 직접 열람하지 못했다. Vercel Vite 프리셋은 [공식 framework 소스](https://github.com/vercel/vercel/blob/main/packages/frameworks/src/frameworks.ts)의 Vite 감지, `VITE_` 접두어와 `dist` 출력을 확인했다. 원본 영상과의 픽셀 단위 일치 여부를 검증했다는 의미는 아니다.

| 자료 | 라이선스 | 조사한 기능 | 결정 |
| --- | --- | --- | --- |
| [simplex-noise.js](https://github.com/jwagner/simplex-noise.js/tree/main) | MIT | 시드 PRNG를 받는 `createNoise2D`/`createNoise3D`, 개별 함수 트리 셰이킹 | 4.0.3을 정확히 고정해 설치. 지형·눈선·구름·물 교란에 적용 |
| [FastNoiseLite](https://github.com/Auburn/FastNoiseLite) | MIT | OpenSimplex, cellular, fractal, domain warp, JS/TS 지원 | 다양한 노이즈를 묶은 대안. 현재 범위는 simplex와 간단한 합성으로 충분해 제외 |
| [Three.js Water](https://github.com/mrdoob/three.js/blob/dev/examples/jsm/objects/Water.js) / [Water2](https://github.com/mrdoob/three.js/blob/dev/examples/jsm/objects/Water2.js) | MIT | 여러 크기의 움직이는 법선, 수면 반사, 흐름 방향, 반사량 | 표현 원리만 참고. 셰이더·이미지를 복사하거나 Three.js를 다시 설치하지 않음. 반사 위치를 다시 샘플링한 ASCII 수면과 파동 합성은 직접 작성 |
| [psrdnoise](https://github.com/stegu/psrdnoise) | GLSL 코드 MIT, 설명 자료는 저장소 고지 참조 | 타일링 가능한 흐름 노이즈, 미분값, WebGL 지원 | 향후 GPU 노이즈 대안. 이번 Canvas 구현에는 포함하지 않음 |
| [PixiJS](https://github.com/pixijs/pixijs) | MIT | GPU 기반 2D 장면 합성과 필터 | GPU 병목 해결이 필요해지면 재검토. 현재는 추가 렌더러 비용을 피함 |

`simplex-noise`의 `master` 브랜치 문서에는 구형 생성자 API가 남아 있어 그대로 사용하지 않았다. 실제 4.0.3 패키지와 `main` 문서의 함수형 API를 기준으로 구현했다. 별도 alea 의존성 대신 프로젝트의 고정 PRNG를 각 노이즈 함수에 따로 전달한다.

## 적용한 표현

- **지형:** 전역 x 좌표를 샘플링한다. 인접 조각이 같은 경계 좌표를 공유하므로 높이가 연결된다. 협곡은 계단형 높이와 층리, 해안은 낮은 섬, 설산은 별도 눈선, 습지는 낮은 능선과 갈대로 구분한다.
- **여행:** 초기 침엽수 강에서 설산·절벽·사암·해안·습지 순환. 화면이 보이고 움직임이 활성화된 시간 180초마다 다음 풍경에 진입한다. 첫 20초 동안 지형 높이·색·식생 크기를 보간한다. 화면 두 장을 겹쳐 투명하게 전환하지 않는다. 자동 여행 스위치는 진행 중 보간도 그대로 멈추고 재개한다.
- **구름:** 서로 다른 속도의 높은 구름과 낮은 구름. 시간축이 있는 3D 노이즈를 최대 3개 주파수로 합성하고 수직 밀도와 문자 밝기에 대응한다. 낮은 화질은 2개 주파수만 사용한다.
- **수면:** 큰 흐름, 잔물결과 노이즈 교란을 합성한다. 지형의 실제 높이·깊이와 구름 노이즈를 반사 위치에서 다시 샘플링하고, 수면의 각 칸에 똑바로 선 ASCII 문자를 하나씩 배치한다. 비트맵 캡처·왜곡·그라데이션 바탕·사각형 반짝임은 사용하지 않는다. 복잡한 광학·유체 시뮬레이션을 수행하는 것은 아니다. 모든 반사와 물결은 공통 해안선 아래에만 그린다.
- **깊이:** 512 높이의 공통 좌표계, 같은 이동 거리와 깊이별 배율. 식생의 뿌리는 강 건너 지면, 전경 뿌리는 아래 강둑에 둔다. 배와 친구는 반사와 수면 위, 가까운 강둑은 그 위에 그린다. 작은 화면에서는 캐릭터 반대편 가장자리에만 큰 전경을 둔다.
- **캐릭터:** 몸체는 16×12 투명 픽셀 격자와 두 색만 사용한다. 하이라이트·둥근 계단 실루엣 없이 직사각 몸통·짧은 팔다리·점눈으로 구성한다. 최종 다리는 3논리 픽셀에서 1논리 픽셀로 줄이고, 발이 배에 붙도록 캐릭터 위치도 조정했다. 배, 항적과 소도구는 별도 도형이다.

## 캐시와 측정

프레임당 문자열·폰트를 다시 그리지 않도록 작은 문자 아틀라스와 반복 패턴을 캐시한다. 지형 조각은 현재 보이는 범위와 양쪽 한 조각을 미리 준비하며, 활성 풍경 두 개와 깊이별 범위에서 벗어난 항목은 해제한다. 문자 아틀라스는 최대 24개, 패턴은 최대 18개다. 구름은 약 8fps, 물은 약 15fps, 합성은 최대 30fps이며 저화질에서는 갱신 빈도와 표본 수를 줄인다. 효과 버퍼는 일반 화질에서 논리 해상도의 65%, 저화질에서 45%로 그린다. 자동 화질은 최근 30프레임 평균 명령 비용이 28ms를 넘으면 저화질 효과로 전환한다. 문자 캐시와 레이어 합성에는 CPU 친화적인 컨텍스트를 사용하고 픽셀 보간을 끈다. 렌더 추적 검사는 배경의 일반 색 채움·선 그리기·외부 이미지·비 ASCII 문자와 CSS 그라데이션 덧씌우기를 거부한다.

노이즈 함수의 3D는 계산에 시간 축을 사용한다는 뜻이며, 캐릭터와 풍경을 3D 메시로 만든다는 뜻은 아니다. `getDiagnostics()`는 최근 최대 120프레임의 렌더 비용과 캐시 수를 제공한다. 이 측정은 JS 그리기 명령 비용이며 실제 GPU·디스플레이 지연이나 실기기 배터리 측정을 대체하지 않는다.

## 라이선스

실제 번들에 포함하는 외부 런타임 패키지는 simplex-noise다. 설치된 4.0.3의 MIT 전문을 `public/third-party-notices.txt`에 보관하며, Vite가 이를 배포 루트 `/third-party-notices.txt`로 복사한다. 다른 프로젝트의 셰이더나 이미지·캐릭터 파일은 포함하지 않는다.
